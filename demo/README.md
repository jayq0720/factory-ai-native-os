# 演示 demo（v0.1）

一个可点击的单文件网页，用于向工厂和合作方演示工厂 AI Native OS 的形态。依据 `docs/development-plan.md`（v0.6）第 2–5 章。

**全部为模拟数据**：客户、项目、文件内容、识别结果、价格均为示例；页面顶部固定显示"模拟数据，非真实识别结果"横幅，审核页按方案 4.7 节的规则禁止导出正式文件。

## 打开方式

- 直接双击 `demo/index.html` 用浏览器打开（无需安装，联网时加载 Google Fonts，断网会退回系统字体）；
- 或在仓库根目录运行 `python3 -m http.server 8000`，访问 <http://localhost:8000/demo/>。

每个页面可以用地址后缀直接打开：`#overview`、`#eng`、`#tender`、`#kiln`、`#kb`。左下角"重置演示数据"可以回到初始状态。

## 五个页面与建议演示顺序（约 10 分钟）

| 页面 | 演示什么 | 对应方案章节 |
|---|---|---|
| 01 工厂总览 | 右侧 IM 里点"让助手识别这张照片" → 确认入库 → 左侧事件账本新增 3 条事件（仓管、质检、采购 Agent 联动）；切换钉钉/企业微信/飞书；点问题芯片演示问数 | 2.4、5.1–5.4、6 |
| 02 技术文件 → 报价 | 开始解析（文字层 + OCR 模拟）→ 点字段定位原文页码并高亮 → 三个选材方案对比，拖动厚度滑块实时重算外壁温度、用量、报价 → 编辑方案/BOM/报价，改折扣触发"低于成本线" → 审核逐条处理风险后提交 L2 | 4.1–4.7 |
| 03 招标文件拆解 | 截止倒计时、需求矩阵按 ★ 实质性/废标风险/负偏离筛选、资料清单自动比对（缺业绩、检测报告过期）、一键转工程项目 | 4.3 |
| 04 窑炉与追溯 | 三条接入路径（直接联网 / 旁路改造 / 拍照读数）；温度曲线与偏差图；Agent 预分析，班长确认执行；批次追溯链 | 3.2、3.3 |
| 05 工程知识库 | 产品库、AI 提议修改（只能提议，管理员确认生效）、衬里模板、修改历史 | 4.4 |

每个页面顶部都有可展开的"演示讲解要点"，按顺序讲即可。

## 计算部分是真的

选材页的传热与用量不是写死的数字：多层平壁一维稳态传热，导热系数 `k(T)=a+bT`，外壁按自然对流 + 辐射（ε=0.8）迭代求解；用量按面积 × 厚度 × (1+损耗) 计算，报价按价格表、折扣、运费、施工费、13% 增值税计算。正式系统中这部分是 Python 确定性代码（方案 4.2 第 6 步），这里用同样的公式在前端实现。产品物性参数是示例值，接入真实产品库后需替换。

## 和正式系统的差别

| demo | 正式系统 |
|---|---|
| 单个 HTML 文件，状态只在浏览器内存中 | Rust 网关 + Python Agent/Worker + PostgreSQL 事件账本 |
| OCR、字段抽取、方案撰写、问答都是预置结果 | Xiaomi-OCR-0（vLLM）、DeepSeek-V3/R1、Qwen，经阿里云百炼调用 |
| IM 对话是页面内模拟 | 钉钉 / 企业微信 / 飞书机器人 |
| 窑炉曲线是生成的示例曲线 | fos-edge 采集（Modbus / OPC UA / 摄像头读数） |
