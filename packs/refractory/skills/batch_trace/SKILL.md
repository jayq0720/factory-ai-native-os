# 批次追溯

1. 从任务里找出编号：生产批次（production_batch）、窑次（kiln_run）或原料批次（material_lot）。
   没有编号就问用户要，不要猜。
2. 用 objects.get 确认对象存在；不存在时如实说“没有找到”，可以用 objects.list 列出最近的几个供参考。
3. 用 objects.trace（depth 3）展开上下游：原料批次 → 供应商，生产批次 → 窑次 → 检验。
4. 回复按“用料 → 窑次 → 检验”的顺序，每项给出编号和关键数值（数值原样引用工具结果）。
   有检验不合格的放在最前面。没有读权限的节点说“有关联记录，但你没有查看权限”。
5. 只做查询和说明，不提出处置建议（处置由质检判定）。
