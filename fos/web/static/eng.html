从技术文件建工程项目

关键工况（温度、气氛、外壁温度、面积、厚度）要先在文档解析页确认或改正。

工程项目

    工程方案：技术文件 → 选材 → 方案 / BOM / 报价 → 审核 → 发布

    1. 在文档解析页上传客户技术要求，核对字段（每个字段带原文页码）。
    2. 回到这里选择文件建项目：工况以账本事件记录，证据是原文页码。
    3. 点“匹配方案”：按衬里模板和硬约束（分类温度余量、外壁温度、厚度、气氛）给出 2–3 个备选方案。
    4. 改厚度、换产品、改折扣 → 传热、用量、报价全部由代码重算，生成新版本。
    5. 逐条处理审核清单后发布报价，按审批规则送销售负责人（必要时总经理）确认。

    温度、用量、金额都由确定性代码计算，模型不参与估算。
